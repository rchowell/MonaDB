== Comparisons

* SQL uses START TRANSACTION, COMMIT, ROLLBACK.
* PostgreSQL uses BEGIN, COMMIT, ROLLBACK.
* DuckDB uses BEGIN TRANSACTION, COMMIT, ROLLBACK/ABORT.

> I prefer abort vs. rollback since it reads more like a ctrl+c whereas rollback seems like something you would do AFTER commit.
