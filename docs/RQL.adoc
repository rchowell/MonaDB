== RQL

_This section will describe the RQL language._

RQL is SQL (ish).

.Notes
- When deciding on language features, I will lean on JS and Lua before SQL.
- No implicit variable names (??)
- No implicit column references.

=== Statements

.DROP TABLE
[source,sql]
----
DROP TABLE <table::name>;
----

=== Query

==== SELECT

[source]
----
<select> := SELECT <item> [, <item>]* [<FROM>]

<item>
    := <variable>
     | <expr> AS <alias>

----

.Rules
1. If a select item is a variable with no alias, the variable name is used as the alias.

[source]
----
<expr>
    := <variable>
     | <value>

<variable> := <identifier>

<value> := <json>
----

=== Types

.Types
[source,sql]
----
type
  : BOOLEAN
  | NUMBER
  | STRING
  | ARRAY
  | OBJECT
  | ANY
----


== Definitions

* Value — a JSON value
* Object — a JSON object value
* Member — key-value pair of an object value
* Item — a value of a collections
* Items — one-or-more values of a collection
* Table — a named collection of items
