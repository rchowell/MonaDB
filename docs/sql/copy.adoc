= COPY

.Examples
[source,sql]
----
copy items to 'items.jsonl'
copy items to 'items.csv'
copy items to 'items.tsv' { header: false }
----

.Syntax
[source]
----
copy_statement
    "copy" copy_source "to" copy_target

copy_source
    table_name
    "(" select_statement ")"

copy_target
    string
    string copy_options

copy_options
    "{"  "}"
----

== FAQ

Q: How can I read data from a file?
A: COPY <file> TO <table>

Q: How can I write data to a file?
A: COPY <data> TO <file>
