= Copy

Copy imports from or exports to CSV, TSV, or JSONL files. Paths are resolved relative to the process working directory.

== Syntax

[source,sql]
----
copy table from string [options]
copy table to string [options]
copy (select_stmt) to string [options]

options
    "{" "}"
----

== Examples

Import:

[source,sql]
----
copy items from 'items.csv'
copy items from 'items.jsonl'
copy items from 'items.tsv' {"header": false}
----

Export:

[source,sql]
----
copy items to 'items.jsonl'
copy items to 'items.csv'
copy (select * from items as i where i.active) to 'active.csv'
----

== Options

Pass `{"header": false}` to skip the header row (CSV/TSV only). Default is `true`.
