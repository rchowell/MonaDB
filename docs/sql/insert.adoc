= Insert Statement

An insert statement begins with the familiar SQL-style `INSERT INTO <table>` followed by a values list. The values list is a comma-separated list surrounded by parentheses.

.Example
[source,rql]
----
insert into points ({ x: 1, y: 2 });

insert into points (
    { x: 1, y: 2 },
    { x: 3, y: 4 },
);

insert into numbers (1, 2, 3);

insert into tuples ([1,2], [3,4]);
----

== Syntax

[source,mckeeman]
----
insert
    "insert" "into" insert_target insert_source

insert_target
    table_name

insert_source
    insert_values
    insert_query

insert_values
    "(" expr_list ")"

expr_list
    expr
    expr "," expr_list
----
