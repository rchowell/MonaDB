= Path

NOTE: Draft. The normative spec is `docs/language.md` 3.3. A subscript on a bare *table* name is keyed table access (`get`), not path navigation — see *Keyed table access* in 3.3.

Paths in _rho_ follow JSONPath with two modifications,

. If the nodelist contains a single value, that value is returned.
. A path expression starts with a table identifier or a variable identifier followed by the root node identifier `$`.

These path expressions are particularly useful in the _from clause_ to iterate over nested collections.

== Syntax

[source,mckeeman]
----
path
    path_identifier
    path_identifier path_parts

path_identifier
    identifier '$'
    '@'

path_parts
    segments

segments
    segment
    segment segments

segment
    "[" selectors "]"
    "." selector_name
    "." selector_wildcard
    ".." "[" selectors "]"
    ".." selector_name
    ".." selector_wildcard

selectors
    selector
    selector "," selectors

selector
    selector_name
    selector_wildcard
    selector_slice
    selector_filter

selector_name
    identifier

selector_wildcard
    "*"

selector_slice
    int ":" int
    int ":" int ":" int

== Rules

. The name selector matches at most one JSON Object member.
. The wildcard selector matches all children of JSON Value.
.. Object children are the member values.
.. Array children are the ordered elements.
.. Primitives have no children.
. The index selector matches at most one JSON Array element.
.. A non-negative index-selector applied to an array selects an array element using a zero-based index.
.. A negative index-selector counts from the array end backwards.

== JSONPath Reference

.Summary
[cols="1m,1",options="header"]
|===
| Syntax | Description

| $
| Root node identifier

| @
| Current node identifier (valid only in filters)

| [<selectors>]
| Selects zero or more children of a node

| .name
| Shorthand for ['name'] or ["name"]

| .*
| Shortcut for [*]

| ..[<selectors>]
| Selects zero or more descendents of a node

| ..name
| Shorthand for ..['name']

| ..*
| Shortcut for ..[*]

| 'name'
| Name selector

| *
| Wildcard selector (all children of node)

| <number>
| Index selector (0-indexed)

| [start:end:step]
| Slice selector (step is optional)

| ?<expression>
| Filter selector

| func(...)
| Function extension

|===
