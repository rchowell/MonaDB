= Pivot

Pivot folds the stream into a single object. Each tuple contributes one member `name: value`. Dual of unpivot.

== Syntax

[source,sql]
----
pivot value at name from source [, source ...]
  [where expr]
----

== Examples

[source,sql]
----
pivot p.price at p.sym from prices as p;
-- [{"amzn": 1900, "goog": 1120}]

pivot price at sym from unpivot {"a": 1, "b": 2} as price at sym;
-- [{"a": 1, "b": 2}]
----

== Rules

- `pivot` requires a `from` clause and yields exactly one object.
- `name` must evaluate to string; non-string tuples contribute no member.
- Repeated `name`: last-wins.
- Empty stream yields `{}`.
- v1 supports `from` and `where` only; `order by` and `limit` are deferred.
