== Schemas

_This section will describe how tables schemas are stored and modified._

Schemas are stored in a table called _catalog_ defined by the following SQL.

[source,sql]
----
CREATE TABLE catalog (
    kind string,    /* TABLE, VIEW, INDEX, etc. */
    name string,    /* Object name */
    sql string,     /* Object schema */
    ptr number,     /* Pointer to root table page */
)
----
