= Unpivot

Unpivot is a from-source that ranges over the attribute-value pairs of an object. Each pair binds its value under `as` and its attribute name under optional `at`. Dual of pivot.

== Syntax

[source,sql]
----
unpivot expr as value [at name]
----

== Examples

[source,sql]
----
select sym, price
from unpivot {"amzn": 1900, "goog": 1120} as price at sym;
-- [{"sym": "amzn", "price": 1900}, {"sym": "goog", "price": 1120}]

select sym, price
from closing as c, unpivot c as price at sym
where sym != 'date';
----

== Rules

- The value alias is required; the `at` name is optional.
- Non-object `expr` yields no rows (inner-join semantics).
- Each object member produces one row.
