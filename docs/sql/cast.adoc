= Casts

The scalar type names `int`, `float`, `string`, `bool`, and `number` are callable
as conversion functions, `T(v)`. A `null` argument yields `null`. A conversion that
cannot succeed — a non-numeric string, a non-finite or out-of-range value, or a
non-scalar argument such as an array or object — is a runtime error.

.Syntax
[source]
----
int(v)
float(v)
string(v)
bool(v)
number(v)
----

.Integers and floats
[source]
----
int(2.7)        -- 2      (truncates toward zero)
int(-2.7)       -- -2
int('5')        -- 5
int('2.7')      -- 2
int(true)       -- 1
int(false)      -- 0

float(3)        -- 3.0
float('1.5')    -- 1.5
float(true)     -- 1.0
----

.Strings, booleans, numbers
[source]
----
string(42)      -- "42"
string(true)    -- "true"

bool(0)         -- false
bool(5)         -- true
bool('true')    -- true   (case-insensitive)
bool('false')   -- false

number('7')     -- 7      (int)
number('1.5')   -- 1.5    (float)
number(true)    -- 1
----

== Syntax

[source,mckeeman]
----
expr_cast
    t_scalar "(" expr ")"

t_scalar
    "bool"
    "int"
    "float"
    "number"
    "string"
----
