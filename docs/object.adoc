= Object Constructor

An *object constructor* is zero or more pairs of member names and associated values, enclosed in curly braces (`{}`).

.Example
[source,rql]
----
{
  a: 1 + 2,
  b: uppercase("hello"),
  c: { x: 1, y: 2 },
}
----

== Syntax

[source,mckeeman]
----
expr_obj
    '{' '}'
    '{' members '}'

members
    member
    member ',' members

member
    member_var      // `a`
    member_assign   // `a: 1`
    member_spread   // `...a`

member_var
    expr_var

member_assign
    member_name ':' member_element

member_name
    name
    string

member_element
    expr

member_spread
    '...' expr

name
    utf8 // no surrogate or noncharacter code points
----

== Description

An object constructor is an expression that describes the initialization of an Object. Objects consist of members, which are used to describe an object. The values of object members can either contain primitive data types or other objects.
