== MonaDB

What if SQLite were a xref:DESIGN.adoc[JSON Database]?

.Notes
- Names: monadb, rho, rhodb
- Language inspiration: JavaScript, TypeScript, Lua, SQL, and Python.
- No implicit variable names (??)
- No implicit column references.
