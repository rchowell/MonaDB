= MonaDB

An embedded document database with SQL-ish support.

.Notes
. monadb named after my cat, alludes to mongo (and monetdb), reads nice like duckdb.
. Language inspiration: JavaScript, TypeScript, Lua, SQL, and Python.
. What if Python were the reference language, so Python and SQL customers can use it effectively?
. I want to make it possible to define types and operations, there should be a "trait" for each JSON type.
. Database extensions are _very_ important.

== Goal

By April 1 have a website powered by MonaDB.

== Brainstorming

- Website with playground and dead simple language documentation.
- REPL
- Insert semantics?
    - If you insert an object into a "closed" table, the extra fields are ignored.
    - If you insert an object into an "open" table, the extra fields are stored in a hidden object column.
- Optimizations such as page compaction.

== Advice

* Take the extra time you saved not rewriting your parsing code and spend it improving the compile error messages your compiler shows users. Good error handling and reporting is more valuable to users than almost anything else you can put time into in the front end. - Bob Nystrom
* Consider prefixing with _ to avoid conflicts with user tables.
* Beam has link:https://github.com/apache/beam/tree/master/sdks/java/testing/tpcds/src/main/resources/schemas[TPC schemas as Avro JSON].
