Language reference

MonaDB speaks RQL, a SQL-flavored dialect for documents. This is a placeholder reference distilled from the design notes in docs/sql/.

The clause model

RQL keeps the familiar SQL verbs, but treats each as a transform over bindings.

Statements

select

Maps the input bindings and applies a constructor — an object or a list of select items.

select 1 + 1;

select { p.x, p.y } from points as p;
select p.x as x, p.y as y from points as p;

select * from t;          -- equivalent to { ...t }
select * from t, s;       -- { ...t, ...s }

insert

INSERT INTO <table> followed by a parenthesized, comma-separated values list.

insert into points ({ x: 1, y: 2 });

insert into points (
    { x: 1, y: 2 },
    { x: 3, y: 4 },
);

insert into numbers (1, 2, 3);
insert into tuples ([1,2], [3,4]);

update

Sets one or more columns, optionally filtered by a where clause.

update points set x = 10, y = x + 1 where x = 0;
-- values may also be DEFAULT or NULL

create table

A table is a collection of some type with zero or more constraints. Members are NOT NULL by default; append |null to make one nullable.

create table points;          -- no schema
create table points ();       -- equivalent

create table points ({
    x: number,
    y: number,
    z: number|null,           -- nullable
    ...                       -- open content
}, {
    hash: x,
    sort: y,
});

copy

Moves rows between a table (or query) and a file, with optional encoding options.

copy items to 'items.jsonl';
copy items to 'items.csv';
copy items to 'items.tsv' { header: false };

Clauses

from

Specifies the source: a table, a view, or a subquery. Multiple sources cross-iterate.

from T
from T as t
from T, S

fetch / limit

A concise limit/offset. fetch takes a count or a range, with an optional step.

limit 100
limit 50..100

fetch 100        -- limit 100
fetch 50..100    -- limit 100, offset 50
fetch 50..       -- offset 50
fetch 1..10 step 1

Expressions & types

objects

An object constructor is zero or more name: value members in braces. Members spread with ....

{ a: 1 + 2, b: upper("hello"), c: { x: 1, y: 2 } }

{ ...a, ...b }   -- merge a and b

paths

JSONPath-style traversal, rooted at a table or variable with $. Single matches collapse to the value; especially useful in from to iterate nested collections.

from T$.foo          -- iterate the `foo` members of T
from T$['foo']       -- equivalent
from T$[x, y]        -- select members x and y

cast & coercion

Three interchangeable forms convert between types.

cast(v as bool)
v::bool
bool(v)

bool(0)      -- false      int('3.14')   -- 3
bool('')     -- false      float('1.9')  -- 1.9
bool([])     -- false      int(true)     -- 1

functions

Functions are called by name with positional and named arguments.

read('filepath', options: obj)

identifiers

Any UTF-8 name that isn't reserved. Reserved words include as, create, delete, drop, from, insert, into, select, and table.
