An embedded database with a query language of its own.

MonaDB pairs a small, document-friendly SQL dialect with a stack-based bytecode engine — text in, results out, no server in between.

Read the docs How it works

The pipeline

Every query takes the same path from text to storage.

SQL text→ Lexer→ Parser→ IR→ Compiler→ Vop bytecode→ VM→ LMDB

A taste of RQL

create table points;

insert into points (
    { x: 1, y: 2 },
    { x: 3, y: 4 },
);

select { x: p.x, y: p.y }
  from points as p
 where p.x > 1
 fetch 10;

What's inside

Documents

Objects, arrays, and JSONPath-style traversal are first-class — not bolted on.

Familiar verbs

select, from, where, group, order, limit — mostly the SQL you know, simplified.

Bytecode VM

Queries compile to compact Vop instructions run by a stack machine.

Embedded

Backed by LMDB. No server, no daemon — it lives inside your process.
